# Release Evidence Index

This page is a short navigation aid for the release evidence trail that lives
in this repository.

## For a candidate release

1. Start with [`docs/RELEASE_EVIDENCE_TEMPLATE.md`](RELEASE_EVIDENCE_TEMPLATE.md).
2. Use [`docs/RELEASE_EVIDENCE_EXAMPLE.md`](RELEASE_EVIDENCE_EXAMPLE.md) as a
   filled reference snapshot for the verified ESP-to-LP10 proof.
3. Review [`docs/ESP_TO_LP10_SIGNALCHAIN_EVIDENCE.md`](ESP_TO_LP10_SIGNALCHAIN_EVIDENCE.md)
   for the detailed proof record.
4. Review [`docs/ESP_TO_LP10_SIGNALCHAIN_RESULT.md`](ESP_TO_LP10_SIGNALCHAIN_RESULT.md)
   for the short result snapshot.

## What each artifact is for

- Template: blank candidate worksheet for release evidence.
- Example: filled reference artifact using the verified public proof data.
- Evidence: full proof record and log context.
- Result: short public-facing summary with hashes and repro command.

## When to use it

Use this index when preparing a release candidate, a public GitHub mirror, or
an OEM evidence bundle. It keeps the proof trail compact without exposing the
transport core.
